# Security Policy

## Reporting a Vulnerability

To report a vulnerability in apple-buildwatch, email gerardrecinto@gmail.com. Please do not open a public GitHub issue for it.

Please include:
- What you found and the potential impact
- Steps or a sample build log to reproduce it
- The version from `buildwatch version`
- A suggested mitigation, if you have one

I will reply as soon as I can. Only the latest release is supported.
