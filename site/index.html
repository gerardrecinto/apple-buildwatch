Run it

Needs macOS 14 or later and a Swift 6 toolchain. This builds the tool and triages a sample log.

git clone https://github.com/gerardrecinto/apple-buildwatch.git
cd apple-buildwatch
swift run buildwatch analyze fixtures/xcodebuild-test-failure.log

Prefer a binary? The README has the release download.

Compare two builds and other formats

This checks whether a build got better, got worse, or stayed the same since last time.

swift run buildwatch analyze fixtures/xcodebuild-test-failure.log --format json > old.json
swift run buildwatch analyze fixtures/make-linker-error.log --format json > new.json
swift run buildwatch compare old.json new.json

Output can also be --format markdown. compare exits 1 when a build got worse.

What this page does not do
  • It re-runs the rule table only. Stack frames, git context and owner lookup need the CLI and your repo.
  • Confidence is a fixed number per rule, not a measured accuracy.
  • If two rules match, the earlier one wins. The page lists every rule that matched.
